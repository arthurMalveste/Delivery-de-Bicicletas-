# Delivery-de-Bicicletas-
Sistema que calcula a melhor rota para fazer a entrega. Usando grafos e o algoritmo de dijkistra mapeamos um bairo da cidade de Limeira, a qual cada nó representa uma casa ou partes da rua. E assim podemos traçar a melhor rota considerando a distância em metros e a altitude que o ciclista terá que enfrentar no trajeto
